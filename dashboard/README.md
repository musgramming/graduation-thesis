# Dashboard

Dashboard hỗ trợ phân tích kết quả thi Tốt nghiệp THPT và hỗ trợ ra quyết định lựa chọn nguyện vọng.

## Cấu trúc

```text
pages/          # Các trang của Dashboard
page_modules/   # Layout và callbacks
data/           # Dữ liệu sử dụng bởi Dashboard
assets/         # CSS, JavaScript, hình ảnh
utils/          # Các tiện ích dùng chung
server.py       # Entry point
```

## Cài đặt

```bash
pip install -r requirements.txt
```

## Chạy

```bash
python server.py
```
