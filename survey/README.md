# Survey

Phân tích dữ liệu khảo sát nhằm tìm hiểu nhu cầu, mục đích và các yếu tố ảnh hưởng đến việc lựa chọn nguyện vọng của thí sinh.

## Cấu trúc

```text
input/       # Dữ liệu đầu vào
output/      # Kết quả phân tích
*.ipynb      # Notebook preprocessing và analysis
setup.bat    # Cài đặt môi trường và mở Jupyter Lab
```

## Cài đặt

Trên Windows:

```bat
setup.bat
```

Hoặc cài đặt thủ công:

```bash
pip install -r requirements.txt
```

## Phân tích

* `preprocessing.ipynb`: Tiền xử lý dữ liệu.
* `analysis.ipynb`: Phân tích và trực quan hóa dữ liệu.

Kết quả được lưu trong `output/`.
